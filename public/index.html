API Keys

Generate keys so other programs can connect to BookSeerr. Send the key as an X-Api-Key header (or ?apikey=) to any /api/… endpoint. Keys grant full access — treat them like passwords.

Dashboards (e.g. a homelab start page): hit GET /api/dashboard with your key for a one-call summary — request counts, the latest requests, and Chaptarr/Listenarr health.

Settings

Link your downloaders here — no .env editing or restart needed. Values are saved on the server, so they apply on every browser and phone instantly. Anything saved here overrides the .env file; use "Reset to .env" to go back.

Requests & Approvals
Choose whether requests go straight to your downloaders or wait for you
—
When this is off, new requests from regular users are held as Pending — nothing is sent to Chaptarr or Listenarr until you Approve (or Reject) them on the All Requests page. Per-user overrides (Users → Edit → Auto-approve) always win over this switch, and admins are always auto-approved.
Notifications
Post to Discord (or any webhook) when requests come in
—
In Discord: Server Settings → Integrations → Webhooks → New Webhook → Copy Webhook URL. BookSeerr detects Discord automatically and sends a rich embed; any other URL receives plain JSON. Treat this URL like a password — anyone who has it can post to your channel.
